# Documentação dos cases

Este diretório registra as premissas analíticas, regras de negócio, dados sintéticos e escolhas visuais dos painéis apresentados no portfólio.

Os quatro cases são demonstrativos. Nomes de pessoas, empresas, prestadores, instituições, valores, comentários, ocorrências e indicadores foram criados para fins de estudo. Nenhuma conclusão representa uma organização real.

## Estrutura de análise

Cada case segue a mesma sequência de trabalho:

1. Definição do problema e da decisão apoiada.
2. Determinação da granularidade dos dados.
3. Regras de cálculo e classificação.
4. Visuais que respondem às perguntas de negócio.
5. Limitações, validação e próximos passos.

## Princípios de uso responsável

- Indicadores de risco e de experiência apontam sinais, não comprovam fraude, falha operacional ou causalidade.
- Decisões clínicas, de alta e de tratamento dependem da avaliação dos responsáveis técnicos.
- Métricas de NPS e menções servem para levantar hipóteses; recomenda-se validar resultados com a operação e com dados completos antes de agir.
